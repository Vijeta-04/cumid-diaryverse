# Diaryverse — cumid.store
A little world of your stories. Interactive 3D diary previewer (React + Vite + Tailwind + CSS 3D transforms, no 3D library).

    npm install
    npm run dev      # development
    npm run build    # production build

Cart and wishlist are frontend-only and persist in localStorage. There is no payment or backend.
Studio controls: drag the diary (or use arrow keys when focused), rotate, flip, zoom, reset.
